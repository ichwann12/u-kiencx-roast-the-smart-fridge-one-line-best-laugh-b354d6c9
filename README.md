## The line

> My smart fridge texts me at 3 a.m. to say the milk expired, then orders a replacement with my card. It is not a fridge. It is a roommate with a keypad.

## Run

```sh
node main.ts
```

Reads the entry from `entry.txt` and writes it to `output.txt` in the
output directory (`MAKEFUN_OUTPUT_DIR`, else `MAKEFUN_BOT_DIR`, else
`./output`). Node stdlib only — no network, no wall clock.
